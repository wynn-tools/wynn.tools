# wynn.tools

A unified home for Wynncraft community tools — Builder, Map, Crafter, and Atlas — with a sharing layer for builds, routes, and overlays.

## Tools

- **Builder** — class build calculator with damage, EHP, spell costs, and ability tree
- **Map** — interactive world map with territories, POIs, and route overlays
- **Crafter** — crafting recipe calculator
- **Atlas** — item and ingredient search with advanced filtering

## Development

**Prerequisites:** Node.js 20+, pnpm

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm test:run   # run tests
pnpm build      # production build
```
